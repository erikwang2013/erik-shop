- المحرك: InnoDB | الترميز: utf8mb4 | الترتيب: utf8mb4_unicode_ci
- المفتاح الأساسي: BIGINT (معرّف Snowflake الموزع، غير ذاتي الزيادة)
- جميع جداول الأعمال تحتوي على `created_at` / `updated_at` / `deleted_at`
- سياسة بادئة الجداول: جداول النظام `wa_`، جداول الأعمال `erik_`
- الفهارس: `install.sql` يحتوي تعريفات فهارس كاملة

## 8. دليل التشغيل

```bash
# 1. إعداد البيئة
cp service/.env.example service/.env   # حرّر واملأ القيم الفعلية
cp admin/.env.example admin/.env       # حرّر واملأ القيم الفعلية

# 2. تثبيت التبعيات
cd service && composer install
cd ../admin && composer install

# 3. استيراد قاعدة البيانات
mysql -u root -p < install.sql

# 4. تشغيل الخدمات
cd service && php start.php start -d
cd ../admin && php start.php start -d

# 5. النشر عبر Docker
docker-compose up -d

# 6. تشغيل الاختبارات
cd service && php vendor/bin/phpunit tests/
```

## 9. الخلاصة

أساس الكود في المشروع متين، والحماية الأمنية شاملة، وتصميم البنية منطقي. الوضع الحالي بعد الإصلاحات:
1. وحدات TODO الوظيفية الأربع (PayPal/التوصيات/التصدير/GeoIP) منفذة بالكامل
2. اكتملت أدوات CI/CD وإدارة جودة الكود (مصفوفة CI وPHPStan وphp-cs-fixer)
3. تسجيل الدخول الاجتماعي يُرجع JWT الآن
4. اختبارات أتمتة Admin ما زالت فارغة (يُقترح إضافتها لاحقًا)
5. المهام المجدولة (10 Cron) منفذة بالكامل واجتازت التحقق من الدخان

يُقترح معالجة العناصر ذات الأولوية العالية أولًا، ثم الدخول في النشر الإنتاجي بعد اكتمال الأدوات.
