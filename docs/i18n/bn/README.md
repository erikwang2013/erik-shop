## প্রকল্প পরিচিতি

webman ফুল-স্ট্যাক ইকোসিস্টেমের উপর নির্মিত ক্রস-বর্ডার ই-কমার্স প্ল্যাটফর্ম, যা B2C/B2B পরিস্থিতি এবং তৃতীয় পক্ষের বিক্রেতা অনবোর্ডিং কভার করে।

### প্রযুক্তিগত আর্কিটেকচার

| স্তর | প্রযুক্তি | ডিরেক্টরি |
|------|------|------|
| বিজনেস API | webman + illuminate/database + erikwang2013/* | `service/` |
| অ্যাডমিন প্যানেল | webman-admin + LayUI + ECharts | `admin/` |
| ক্লায়েন্ট | Flutter (iOS/Android/macOS/Windows/Linux) | `apps/flutter/` |
| হারমোনি ক্লায়েন্ট | ArkTS + ArkUI (HarmonyOS NEXT) | `apps/harmonyos/` |

### প্রযুক্তি স্ট্যাক

**সার্ভার-সাইড:** PHP 8.3+, webman 2.1, MySQL 8.0, Redis 7, Elasticsearch 8
**কোর প্যাকেজ:** snowflake-php, hashids, jwt-webman, encryption, encryptable, poster-php, webman-scout, season
**পেমেন্ট:** Stripe, PayPal (সম্পূর্ণ); Klarna, Adyen (প্লেসহোল্ডার, `PaymentGateway::make` অসম্পূর্ণ, দেখুন docs/PLAN.md)
**ক্লায়েন্ট:** Flutter 3.x (Riverpod + GoRouter + Dio), HarmonyOS API 12+ (ArkTS + ArkUI)

### মাল্টি-কারেন্সি সেটেলমেন্ট ব্যাখ্যা

**মাল্টি-কারেন্সি প্রাইসিং**: পণ্যের SKU `currency_code` অনুযায়ী আলাদা কারেন্সিতে মূল্য নির্ধারণ করা হয়, অর্ডার করার সময় অর্ডারটি রিসিভিং কারেন্সি লক করে (USD / EUR / GBP / CNY ইত্যাদি)।

**এক্সচেঞ্জ রেট সার্ভিস**: `erik_exchange_rates` রেট টেবিল manual ম্যানুয়াল মেইনটেনেন্স এবং exchangerate-api অটো-ফেচ সমর্থন করে, `effective_at` ইফেক্টিভ টাইম অনুযায়ী ভার্সন ম্যানেজমেন্ট করা হয়, সেটেলমেন্টের সময় পেমেন্ট মুহূর্তের রেট স্ন্যাপশট নেওয়া হয়।

**অরিজিনাল কারেন্সিতে চার্জ**: Stripe / PayPal অর্ডারের কারেন্সিতে চার্জ করে (Klarna/Adyen প্লেসহোল্ডার, সংযুক্ত নয়), Webhook সিগনেচার ভেরিফিকেশনের পরে পেমেন্ট ও অর্ডার স্ট্যাটাস আপডেট হয়।

**প্রফিট-শেয়ারিং সেটেলমেন্ট**: পেমেন্ট সফল হওয়ার পর স্বয়ংক্রিয়ভাবে `PlatformSettlements` প্ল্যাটফর্ম সেটেলমেন্ট তৈরি হয় (অর্ডার টোটাল + প্ল্যাটফর্ম কমিশন + পেমেন্ট গেটওয়ে ফি, অর্ডারের কারেন্সিতে লেজার করা হয়); মার্চেন্ট সেটেলমেন্ট `MerchantSettlements` (অর্ডার অ্যামাউন্ট → কমিশন রেট → সেটেলমেন্ট অ্যামাউন্ট), সাপ্লায়ার সেটেলমেন্ট `SupplierSettlements`, অ্যাফিলিয়েট কমিশন উইথড্রয়াল `AffiliatePayouts` — চারটি লাইন আলাদাভাবে সেটেল হয়, স্ট্যাটাস 0 মুলতুবি / 1 সেটেল্ড।

**ফরেক্স গেইন/লস**: `CurrencyExchangeGainsLosses` রিসিভ কারেন্সি ও সেটেলমেন্ট কারেন্সির পার্থক্য ট্র্যাক করে, পেমেন্টের সময় রেট বনাম সেটেলমেন্টের সময় রেট তুলনা করে, পজিটিভ = ফরেক্স গেইন, নেগেটিভ = ফরেক্স লস, ক্রস-বর্ডার ই-কমার্স মাল্টি-কারেন্সি রিকনসিলিয়েশন ও অডিট সমর্থন করে।

## দ্রুত শুরু

### পদ্ধতি ১: ওয়েব ওয়ান-ক্লিক ইনস্টলেশন (প্রস্তাবিত)

```bash
# 1. admin ডিপেন্ডেন্সি ইনস্টল
cd admin && composer install

# 2. অ্যাডমিন প্যানেল চালু করুন
php start.php start -d

# 3. ব্রাউজারে ইনস্টলেশন উইজার্ড খুলুন
# http://127.0.0.1:8788/app/admin/install/step1
# ডেটাবেস তথ্য দিন → অ্যাডমিন অ্যাকাউন্ট সেট করুন → সম্পন্ন

# 4. ডিপেন্ডেন্সি ইনস্টল করে API চালু করুন
cd ../service && composer install && php start.php start -d
```

> ইনস্টলেশন উইজার্ড স্বয়ংক্রিয়ভাবে সম্পন্ন করে: ডেটাবেস তৈরি → 117টি টেবিল ইমপোর্ট → service/.env এবং admin/.env তৈরি (র্যান্ডম কী সহ) → অ্যাডমিন তৈরি → সার্ভিস রিলোড

### পদ্ধতি ২: কমান্ড লাইন ম্যানুয়াল ইনস্টলেশন

বিস্তারিত দেখুন [INSTALL.md](INSTALL.md)

cp .env.example .env  # অথবা DB_PASS / JWT_SECRET ইত্যাদি ভেরিয়েবল সেট করুন

## কোর ডিজাইন

- **Snowflake প্রাইমারি কী**: 117টি টেবিল সব `erikwang2013/snowflake-php` দিয়ে তৈরি bigint ID ব্যবহার করে
- **Hashids ইন্টারফেস**: মিডলওয়্যার স্বয়ংক্রিয়ভাবে এনকোড/ডিকোড করে, কন্ট্রোলার অনবেয়ার
- **Encryptable এনক্রিপশন**: email/mobile/address ইত্যাদি সংবেদনশীল ফিল্ড ডেটাবেস লেভেলে এনক্রিপ্ট হয়
- **JWT অথেনটিকেশন**: HS256 + access/refresh ডুয়াল-টোকেন অটো-রিফ্রেশ
- **API ভার্সন**: `API-Version` header রাউটিং, URL-এ নয়
- **Poster ভেরিফিকেশন**: সংবেদনশীল অপারেশন (রেজিস্ট্রেশন/অর্ডার/পেমেন্ট) র্যান্ডম হিউম্যান ভেরিফিকেশন
