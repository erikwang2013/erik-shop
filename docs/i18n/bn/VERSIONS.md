```

Standard:  Cors → Security(4 প্রকার) → Platform → GeoIp → Locale
          → HashidsDecode → VersionRoute
          → (PosterVerify) → (JwtAuth) → HashidsEncode

Full:       Cors → Security(31 প্রকার) → RateLimit(টোকেন বাকেট) → Platform → GeoIp
          → Locale → HashidsDecode → VersionRoute
          → (PosterVerify) → (JwtAuth) → HashidsEncode → Encryption(ইন্টারফেস এনক্রিপশন)
```

## আপগ্রেড পাথ

```
Lite (ওপেন সোর্স) ──→ Standard (কমার্শিয়াল) ──→ Full (কমার্শিয়াল)

আপগ্রেড পদ্ধতি:
  1. সংশ্লিষ্ট ভার্সনের কোডের জন্য erik@erik.xyz-এ যোগাযোগ করুন
  2. ইনক্রিমেন্টাল schema ইমপোর্ট করুন (lite→standard ~40টি টেবিল যোগ, standard→Full ~48টি টেবিল যোগ)
  3. সংশ্লিষ্ট ভার্সনের কন্ট্রোলার/মডেল/মিডলওয়্যার কপি করুন
  4. composer require নতুন ডিপেন্ডেন্সি প্যাকেজ
```
