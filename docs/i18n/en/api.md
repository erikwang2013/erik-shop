## General Conventions

### Request Format

| Item | Description |
|------|------|
| Base URL | `http://localhost:8787/api` |
| Version control | `API-Version: 2026-05-20` header (not in URL) |
| Authentication | `Authorization: Bearer <token>` header |
| Language | `Accept-Language: zh_CN|zh_HK|en|ja|ko` header |
| Platform | `X-Platform: ios|ipados|macos|windows|linux|android|harmonyos|web` header |
| Content-Type | `application/json` (POST/PUT) |
| Human verification | `X-Poster-Token: <token>` header (sensitive operations) |

### Response Format

```json
// Success
{"code": 0, "msg": "ok", "data": {}}

// Failure
{"code": 1, "msg": "error message", "data": null}

// Pagination
{"code": 0, "msg": "ok", "data": {"list":[], "total":100, "page":1, "per_page":20}}

// Error codes
// 40001 XSS attack  40002 SQL injection  40003 CRLF injection  40004 Path traversal
// 40005 Request body too large  40006 Content-Type error  40008 Brute force
// 40009 File upload violation  40010 XXE injection  40011 SSRF attack
// 40012 HTTP method error  40013 Host header error
// 401 Not logged in  403 Forbidden  422 Parameter validation failed  429 Too many requests  503 Service unavailable (circuit breaker/degradation)
```

### ID Explanation

All ID fields in the API are hashids-encoded strings (e.g. `Ab3xK9pq`), automatically encoded/decoded by middleware. No manual handling needed on the frontend.

## Appendix: API Design Conventions

### Version Control

Version is passed via the `API-Version: 2026-05-20` header, not in the URL. Mapped by the VersionRoute middleware.

### Middleware Pipeline

```
Cors → Security(31 types) → RateLimit(sliding window) → Platform(8 platforms) → GeoIp → Locale
    → HashidsDecode → VersionRoute → (PosterVerify) → (JwtAuth) → HashidsEncode → Encryption
```

### Endpoint Statistics

- Public APIs: 23 (auth/product/category/content/search/service)
- Authenticated APIs: 47 (user/cart/order/payment/return/review/marketing)
- Webhook: 1 (payment callback)
- Admin: 1 (refund execution)
- Health: 1 (/health health check)

### Unified Response

```json
{"code": 0, "msg": "ok", "data": {}}
{"code": 1, "msg": "error", "data": null}
{"code": 0, "msg": "ok", "data": {"list":[], "total":100, "page":1, "per_page":20}}
```

### hg/apidoc Dynamic Documentation

Generated automatically from controller annotations using hg/apidoc. Visit `/apidoc/` after startup.

Annotation example:
```php
/**
 * @Apidoc\Title("User Login")
 * @Apidoc\Method("POST")
 * @Apidoc\Url("/api/auth/login")
 * @Apidoc\Param(name="email", type="string", require=true)
 * @Apidoc\Returned(name="access_token", type="string")
 */
public function login(Request $request) { ... }
```
