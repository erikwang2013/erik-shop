## 3. Middleware Pipeline

```
Service: Cors → Security (31 attack detection types) → RateLimit (token bucket) → Platform (8-platform identification)
        → GeoIp (region) → Locale (language) → HashidsDecode → VersionRoute
        → (PosterVerify human verification) → (JwtAuth Token) → HashidsEncode → Encryption (interface encryption)

Admin:  Security → Platform → HashidsDecode → AccessControl (built-in RBAC) → HashidsEncode
```

## 4. Security

- **31 attack detection types**: XSS/SQL injection/command injection/CRLF/path traversal/Body/ContentType/file upload/brute force/XXE/SSRF/deserialization/LDAP/email header/SSTI/NoSQL/open redirect/JWT attacks/Host/request smuggling/GraphQL/XPATH/Log4Shell/SSI/CSV formula/data leakage/prototype pollution/WebSocket/CORS/DNS rebinding/HTTP method/CSRF Origin
- **Three-layer encryption**: interface layer (AES-256-CBC) + database layer (Encryptable trait) + ID obfuscation (Hashids)
- **Platform tracking**: 8 platforms (iOS/iPadOS/macOS/Windows/Linux/Android/HarmonyOS/Web) + X-Platform header + recorded in 6 tables

## 5. High Concurrency

- **Rate limiting**: token bucket sliding window (Redis ZSET), 6 endpoint rules
- **Circuit breaker/degradation**: Redis circuit breaker — external API calls (payment gateways/social login), 5 consecutive failures → 30s open, half-open probe auto-recovers; business rejections don't count as failures; Redis failure auto-degrades to pass-through (503)
- **DB**: read/write split (2 read replicas + sticky) + connection pool (50/10)
- **Slow operations**: handled by dedicated Cron processes (Feed sync/recommendation calculation/payment reconciliation/settlement etc.)

## 6. Testing

22 tests / 45 assertions — ALL PASS
- SecurityTest (12): XSS+SQLi+XXE+SSRF+Path+data leakage
- JwtTest (4): encode/decode validation
- ApiResponseTest (3): success/fail/paginate

## 7. Deployment

```bash
# Docker
docker compose up -d  # nginx + service + admin + mysql + redis + es

# Manual
cd service && php start.php start -d
cd admin && php start.php start -d
```

- **Multilingual (i18n)**: 5-language translation files + LocaleMiddleware + Flutter AppLocalizations
- **API documentation**: auto-generated by hg/apidoc (6 groups, annotation-driven controllers)
- **Platform tracking**: 8-platform X-Platform header + DB records
- **CDN (origin-pull)**: uploads stay on the admin origin, DB stores relative paths only; at output boundaries `Cdn::url()` rewrites to `https://{CDN_DOMAIN}{path}`; edge cache 7-day immutable + auto-purge (fail-open) on product/banner CRUD
