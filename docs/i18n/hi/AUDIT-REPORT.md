## 6. आर्किटेक्चर मूल्यांकन

### 6.1 शक्तियाँ

1. **स्पष्ट स्तरीय आर्किटेक्चर**: Controller / Model / Common, जिम्मेदारियाँ स्पष्ट
2. **API संस्करण नियंत्रण**: URL संस्करण संख्या की तुलना में Header विधि अधिक सुरुचिपूर्ण
3. **मिडलवेयर पाइपलाइन**: कंपोज़ेबल, क्रमबद्ध सुरक्षा और व्यावसायिक मिडलवेयर
4. **बहुभाषी/बहु-मुद्रा**: उत्पाद अनुवाद टेबल + SKU मुद्रा-वार मूल्य टेबल डिज़ाइन उचित
5. **HS Code टैरिफ**: पूर्ण क्रॉस-बॉर्डर कस्टम कर दर गणना प्रणाली
6. **उच्च समवर्ती तैयारी**: कनेक्शन पूल, रीड/राइट स्प्लिटिंग, टोकन बकेट रेट लिमिट, OPCache सभी कॉन्फ़िगर |
7. **भुगतान एब्स्ट्रैक्शन**: `PaymentGateway` फ़ैक्टरी पैटर्न, नए चैनल जोड़ना आसान
8. **सुरक्षा गहराई**: 31 प्रकार की हमले पहचान + डेटाबेस एन्क्रिप्शन + ID अस्पष्टीकरण + मानव-सत्यापन

## 7. डेटाबेस समीक्षा

- **117 टेबलें** (7 `wa_` सिस्टम टेबल + लगभग 110 `erik_` व्यावसायिक टेबल)
- इंजन: InnoDB | कैरेक्टर सेट: utf8mb4 | कॉलेशन: utf8mb4_unicode_ci
- प्राथमिक कुंजी: BIGINT (Snowflake वितरित ID, गैर-ऑटोइन्क्रीमेंट)
- सभी व्यावसायिक टेबलों में `created_at` / `updated_at` / `deleted_at`
- टेबल उपसर्ग नीति: सिस्टम टेबल `wa_`, व्यावसायिक टेबल `erik_`
- इंडेक्स: `install.sql` में पूर्ण इंडेक्स परिभाषाएँ शामिल

## 8. चलाने की गाइड

```bash
# 1. पर्यावरण तैयारी
cp service/.env.example service/.env   # वास्तविक मान भरकर संपादित करें
cp admin/.env.example admin/.env       # वास्तविक मान भरकर संपादित करें

# 2. निर्भरताएँ स्थापित करें
cd service && composer install
cd ../admin && composer install

# 3. डेटाबेस आयात करें
mysql -u root -p < install.sql

# 4. सेवाएँ शुरू करें
cd service && php start.php start -d
cd ../admin && php start.php start -d

# 5. Docker तैनाती
docker-compose up -d

# 6. टेस्ट चलाएँ
cd service && php vendor/bin/phpunit tests/
```
