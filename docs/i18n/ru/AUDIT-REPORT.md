## 6. Оценка архитектуры

### 6.1 Преимущества

1. **Чёткая многоуровневая архитектура**: Controller / Model / Common, обязанности разделены
2. **Версионирование API**: способ с заголовком элегантнее номера версии в URL
3. **Конвейер промежуточного ПО**: компонуемые, упорядочиваемые промежуточные обработчики безопасности и бизнес-логики
4. **Многоязычность/мультивалютность**: таблица переводов товаров + таблица цен SKU по валютам спроектированы грамотно
5. **Пошлины HS Code**: полная система расчёта трансграничных таможенных ставок
6. **Готовность к высоким нагрузкам**: пул соединений, разделение чтения/записи, token bucket, OPCache — всё настроено
7. **Абстракция оплаты**: фабричный шаблон `PaymentGateway`, легко расширять новыми каналами
8. **Глубина защиты**: обнаружение 31 типа атак + шифрование БД + обфускация ID + проверка «человек или робот»

